# PaySim Fraud Detection

This repository is being rebuilt as a reproducible fraud-detection case study on the PaySim dataset.

The goal of this project is to compare simple rule-based fraud heuristics against lightweight supervised machine learning baselines on a highly imbalanced financial-transactions dataset.

Current status:

- code-first project scaffold in progress
- legacy notebooks being migrated into reusable `src/` modules
- final README, metrics, and charts will be added after the pipeline is implemented

Dataset source:

- [PaySim on Kaggle](https://www.kaggle.com/datasets/ealaxi/paysim1)
