# CV Bullets

## English

- Built a code-first fraud-detection case study on the PaySim dataset, refactoring exploratory notebook work into reusable Python modules for data validation, feature engineering, model training, and evaluation.
- Implemented interpretable rule-based fraud baselines and compared them against Logistic Regression and Random Forest on an imbalanced transaction dataset using precision, recall, F1, and PR-AUC.
- Designed a reproducible local experiment workflow with automated tests, deterministic train/validation/test splits, exported metrics, and confusion-matrix artifacts for portfolio-ready reporting.

## Vietnamese

- Xây dựng project phát hiện gian lận theo hướng code-first trên bộ dữ liệu PaySim, refactor phân tích notebook ban đầu thành các module Python tái sử dụng cho kiểm tra dữ liệu, tạo feature, huấn luyện và đánh giá mô hình.
- Cài đặt baseline rule-based dễ giải thích và so sánh với Logistic Regression và Random Forest trên bài toán dữ liệu lệch lớp, sử dụng các metric phù hợp như precision, recall, F1 và PR-AUC.
- Thiết kế quy trình thực nghiệm có thể tái lập trên máy local với test tự động, train/validation/test split cố định, xuất metrics và confusion matrix phục vụ portfolio và CV.
